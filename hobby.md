# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов. Пользователь отправляет
сообщение вида "кофе 250" — бот сохраняет трату в базу, распределяет её
по категориям и по команде /report присылает сводку за неделю и месяц.

Стек: Python (aiogram), PostgreSQL, Docker, GitHub Actions.

Цель: научиться доводить проект от идеи до работающего сервиса —
написать бота, упаковать его в контейнер, настроить автодеплой на сервер
и следить за ним через логи. Основной интерес — не столько сам код,
сколько инфраструктура вокруг него.
