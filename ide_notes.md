# Git в IDE и в терминале
 
## Удобно в VS Code
1. Наглядный просмотр diff по каждому файлу в два столбца.
2. Постадийное добавление в индекс отдельных строк (stage selected ranges).
3. Встроенный редактор merge-конфликтов с кнопками выбора варианта.
 
## Удобнее в терминале
- Интерактивный rebase (git rebase -i): полный контроль над списком
  коммитов и действиями pick/reword/squash/fixup/drop.
