# Цели на семестр

## 1. Освоить Git на уровне уверенного пользователя
Научиться работать не только с базовыми командами (add, commit, push),
но и с ветвлением, rebase, разрешением конфликтов и Pull Request'ами.
Критерий: к концу семестра веду весь учебный проект через feature-ветки
и осмысленные коммиты по Conventional Commits.

## 2. Научиться контейнеризировать приложения
Разобраться с Docker: образы, контейнеры, Dockerfile, docker-compose.
Критерий: самостоятельно упаковать Python-приложение из сквозного проекта
в контейнер и запустить его вместе с базой данных одной командой.

## 3. Собрать CI/CD-пайплайн
Изучить GitHub Actions и настроить автоматическую сборку и прогон тестов
при каждом Pull Request.
Критерий: в репозитории devops-course-2026 работает workflow, который
блокирует merge при падении проверок.
